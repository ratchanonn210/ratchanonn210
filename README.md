### 🚀 Featured Project

#### [Retail Data Engineering Pipeline](https://github.com/ratchanonn210/retail-data-pipeline)

An end-to-end batch data pipeline built with Python, PySpark, SQL, Databricks, and Delta Lake, following the Bronze, Silver, and Gold medallion architecture.

**Key Features**

- **Bronze Layer:** Incremental ingestion of raw retail transaction data.
- **Silver Layer:** Data cleaning, validation, and rejected-record handling.
- **Gold Layer:** Analytics-ready aggregate tables for business analysis.
- **Data Quality:** Reconciliation checks to validate data consistency.
- **Idempotency:** Checks to verify repeatable pipeline execution.
